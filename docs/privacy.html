Privacy Policy

Finance Tracker · last updated 7 September 2026

Finance Tracker is a personal, self-hosted budgeting tool built and run by one individual for their own private use. It is not a company, not a product, and is not offered to the public. This page explains what it does with data.

Who runs it

A single private individual (the "operator"), for their own personal finances only. There are no other users, no staff, and no organisation behind it.

What data is involved

  • Bank account information retrieved through Enable Banking's API with the operator's explicit consent: account details (name, IBAN, currency), balances, and transaction history.
  • Access is read-only. The application cannot and does not initiate payments or move money.
  • No data is collected from anyone other than the operator's own bank accounts. There are no visitor accounts, sign-ups, or forms.

Where it is stored

  • All retrieved data is written to a local SQLite database file on the operator's own machine.
  • Nothing is uploaded to a hosted server, shared with third parties, sold, or used for advertising. There is no analytics, tracking, or telemetry.
  • The private key and database file are excluded from version control and are never published.

Third parties

The only third party is Enable Banking, which brokers the regulated connection to the bank. Their handling of data is governed by their own privacy policy and by the operator's bank. This page covers a private client that talks to that API.

Retention and revoking access

  • Data stays in the local database until the operator deletes it. There is no fixed retention period because there is no service operating it.
  • Consent to access the bank data can be withdrawn at any time through Enable Banking or directly with the bank, which stops any further access.

Changes
